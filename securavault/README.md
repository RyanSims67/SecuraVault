# SecuraVault

SecuraVault is a basic password manager created for this project.

## Planned Features

- Create password entries
- View saved password entries
- Edit password entries
- Delete password entries
- Search password entries
- Generate strong random passwords
- Encrypt passwords before storage

## Project Structure

- `src/models/` – domain models
- `src/services/` – application logic
- `src/storage/` – local persistence
- `src/ui/` – CLI or GUI entry point
- `tests/` – unit tests
- `data/` – local application data
