# Mission
SecuraVault is a small password manager project for the Software Engineering (Task B) assignment.

The goal of SecuraVault is to let users manage passwords in a simple local vault. The project will support creating, viewing, editing, deleting, searching, and generating password entries. Password values should be encrypted before they are stored.

This project is not intended to replace a professional password manager. The main purpose is to demonstrate software engineering methods such as requirements engineering, Git, UML, DDD, clean code, refactoring, testing, metrics, build management, CI/CD, and documentation.

## Project Goals

- Build a small working password manager prototype.
- Keep password entries structured and manageable.
- Encrypt passwords before storage.
- Provide a password generator.
- Keep the code understandable and easy to modify.
- Document the development process clearly in GitHub.

## Out of Scope

- Browser extension
- Cloud sync
- Mobile app
- Real production password storage
- Multi-user enterprise password sharing
